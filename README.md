# TaskFlow – To-Do Web App

**SkillCraft Technology Web Development Internship – Task 04**

## About the Project

TaskFlow is a responsive To-Do Web Application developed using HTML, CSS, and JavaScript.

The application helps users organize their daily tasks by allowing them to add tasks, set dates and times, mark tasks as completed, edit existing tasks, delete tasks, and filter tasks based on their status.

## Features

* Add new tasks
* Set task date and time
* Mark tasks as completed
* Edit existing tasks
* Delete tasks
* Filter tasks by:

  * All
  * Active
  * Completed
* Clear all completed tasks
* Active task counter
* Empty-state message
* Responsive design for mobile and desktop
* Local Storage support to preserve tasks after refreshing the page
* Modern and clean user interface

## How It Works

1. Enter a task in the input field.
2. Optionally select a date and time.
3. Click **Add Task**.
4. Use the checkbox to mark a task as completed.
5. Use **Edit** to update an existing task.
6. Use **Delete** to remove a task.
7. Use the filters to view All, Active, or Completed tasks.
8. Use **Clear Completed** to remove completed tasks.

Tasks are stored using the browser's **Local Storage**, so they remain available even after refreshing the page.
